# Consistency-Driven Drafting

This is the screenwriting equivalent of Test-Driven Development. The discipline is: know what a scene must accomplish before writing it, verify the draft meets those requirements, then improve craft without breaking function.

## The Cycle: CRITERIA → DRAFT → POLISH

### Step 1: CRITERIA (Write the "test")

Before writing a single line of action or dialogue, state the scene's acceptance criteria. These come from the beat sheet entry. If there is no beat sheet entry, write the criteria now.

Example criteria for a scene:

```
This scene must:
1. Reveal that Jake knows about the affair — through his behavior, not exposition
2. Shift the power dynamic from Elena to Jake by the scene's end
3. End on a moment of silence, not a line of dialogue
4. Stay under 3 pages
5. Establish the physical detail of the ticking clock on the mantle (plant for Act 3)
```

Criteria must be **functional** (what the scene does) not **aesthetic** (how it sounds). Craft comes in the POLISH step.

### Step 2: DRAFT (Write the minimal scene that passes)

Write the scene. Focus entirely on meeting the criteria. Don't worry about perfect dialogue or lyrical action lines — just make the scene *work*.

After drafting, check every criterion:
- [ ] Criterion 1: Pass / Fail
- [ ] Criterion 2: Pass / Fail
- [ ] Criterion 3: Pass / Fail
- [ ] Criterion 4: Pass / Fail
- [ ] Criterion 5: Pass / Fail

If any criterion fails, revise the draft until all pass. Do NOT move to polishing with failing criteria.

### Step 3: POLISH (Improve without breaking)

Now improve the scene's craft:
- Sharpen dialogue — remove on-the-nose lines, add subtext, differentiate voices
- Trim action lines — cut adjectives, use active verbs, show don't tell
- Strengthen visual storytelling — can any dialogue beat be replaced with a visual?
- Improve rhythm — vary sentence length in action lines, vary speech length in dialogue
- Add sensory detail — what does the audience see, hear? (Not smell, taste, touch — this is film)

**After every polish pass, re-check the criteria.** If polishing broke a criterion (common: trimming a scene below 3 pages but accidentally cutting the plant), roll back the polish that caused the break. Craft never trumps function.

## Rules

### Criteria come from the beat sheet

If a beat sheet exists, the criteria ARE the acceptance criteria from the beat entry. Don't invent new criteria that weren't in the plan unless you discover something the plan missed — and if you do, note it and update the beat sheet.

### One scene at a time

Never draft two scenes in one pass. Each scene is a complete CRITERIA → DRAFT → POLISH cycle. This prevents the common failure mode where Scene B subtly undermines Scene A during drafting.

### Read the previous scene's last lines before drafting

Continuity matters. Before drafting Scene N, read the last 5-10 lines of Scene N-1. Match the energy. If Scene N-1 ends on a devastating revelation, Scene N can't open with casual banter unless you're making a deliberate tonal cut (and if so, that should be in the criteria).

### Screenplay format during drafting

Use proper format from the first draft, not as a polish step:
- Scene headings: `INT./EXT. LOCATION - TIME OF DAY`
- Action lines: Present tense, third person, visual and auditory only
- Character cue: ALL CAPS first time, then normal. Centered above dialogue.
- Parentheticals: Only when the line would be misread without one
- No camera directions in spec scripts: No "CLOSE ON," "WE SEE," "ANGLE ON"
- No "we see" or "we hear": The camera isn't a character. "A car pulls up" not "We see a car pull up"

### Dialogue rules during drafting

- **Each character must sound different.** Read the dialogue for one character with all other lines removed. Does it sound like a distinct person?
- **Subtext over text.** Characters rarely say exactly what they mean. If a line could be the character's inner thought spoken aloud, it needs subtext.
- **No maid-and-butler dialogue.** Characters don't tell each other things they both already know for the audience's benefit. Find another way.
- **Shorter is almost always better.** Most speech in scripts runs too long. Cut to the bone.

### Action line rules during drafting

- **Lean prose.** Three lines max per action paragraph. If it's longer, break it up or cut it.
- **Active verbs.** "Sarah crosses the room" not "Sarah walks slowly across the room."
- **No internal states.** You can't film a thought. "Sarah clenches her jaw" (visible) not "Sarah feels angry" (invisible).
- **White space is your friend.** Dense pages read slowly. Readers skim action to get to dialogue — make the action worth reading by making it brief and visual.

## Verification

After completing the CRITERIA → DRAFT → POLISH cycle:

1. Re-read the scene cold. Does it work on its own?
2. Check all criteria one final time — all must pass.
3. Verify page count is within the beat sheet target.
4. Read only the dialogue. Does each character sound like themselves?
5. Read only the action lines. Can you see the scene?

Only after all verification passes is the scene complete.

## Anti-patterns

- **Polishing before the draft passes criteria.** Beautifully written scenes that don't serve the story are the most dangerous kind of bad writing. They're hard to cut because they sound good.
- **Criteria drift.** "Well, the scene didn't quite reveal Jake's knowledge, but it does something interesting..." No. If the scene doesn't pass the criterion, either fix the scene or consciously change the criterion (and update the beat sheet, and check for downstream breaks).
- **Drafting without criteria.** Writing a scene to "see what happens" is brainstorming, not drafting. If you don't know what the scene needs to do, go back to the beat sheet.
- **The polish death spiral.** Polishing a scene 5+ times without criteria changing. If you're still polishing, you're probably avoiding the next scene. Ship it and move on. A good-enough scene that serves the story beats a perfect scene that stalls the draft.
