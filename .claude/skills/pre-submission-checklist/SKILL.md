# Pre-Submission Checklist

This is the final gate. Every item is checked. No exceptions, no shortcuts, no "it's probably fine." A script that goes out with a format error, a missing scene heading, or an orphaned character introduction signals to the reader that the writer doesn't care about the details — and if the writer doesn't care, why should the reader?

## The Checklist

### Format (mechanical)

- [ ] **Title page present**: Title, author name, contact information. No WGA registration number (signals amateur). No draft date unless specifically requested.
- [ ] **Font**: Courier or Courier New, 12pt. (If using Fountain markup, this is handled by the rendering tool.)
- [ ] **Margins**: 1.5" left, 1" right, 1" top and bottom. (Standard spec script margins.)
- [ ] **Page numbers**: Upper right, starting on page 2. No page number on title page.
- [ ] **Scene headings**: Every scene has one. Format: `INT./EXT. LOCATION - TIME OF DAY`. No creative variations ("INSIDE THE BELLY OF THE BEAST" — save it for the action lines).
- [ ] **Character introductions**: Every speaking character is introduced in action lines with their name in ALL CAPS before their first dialogue. Introduction includes a brief, vivid description — not their life story.
- [ ] **No camera direction**: No "CLOSE ON," "WE SEE," "ANGLE ON," "CAMERA PANS TO," "POV" in a spec script. These are the director's job.
- [ ] **No "we see/hear"**: The camera is not a character. "A car pulls up" not "We see a car pull up."
- [ ] **Parenthetical restraint**: Used sparingly. If more than 30% of dialogue has parentheticals, too many.
- [ ] **Page count**: Within format range (feature: 90-120, hour pilot: 50-65, half-hour: 25-35, short: under 15).

### Story (structural)

- [ ] **The first 10 pages**: Read the first 10 pages cold, as if you've never seen the script. Would you keep reading? Is the dramatic question clear by page 10? Do you know whose story this is?
- [ ] **Every scene turns**: Something changes in every scene — power, information, relationship, stakes. If nothing changes, the scene should have been caught in coverage.
- [ ] **Protagonist want is clear**: Can you state in one sentence what the protagonist wants? Can the audience state it by page 15?
- [ ] **Antagonist force is clear**: The obstacle to the protagonist's want is specific, active, and present. Not vague. Not passive.
- [ ] **The ending**: Does the ending answer the thematic question posed by the story? Does the protagonist's final choice reflect their arc (or tragic lack of arc)?
- [ ] **No orphans**: Every plant has a payoff. Every payoff has a plant. No characters introduced and then forgotten. No subplots that trail off.

### Character (voice)

- [ ] **Voice differentiation test**: Pick any page of dialogue with 3+ characters. Cover the character names. Can you tell who's speaking? Do this for at least 3 different pages.
- [ ] **Character want/need/flaw**: Can you state each major character's want, need, and flaw without consulting the Story Bible? If not, the script isn't making them clear enough.
- [ ] **Character names**: No two major characters share a first initial. No names that look or sound too similar (Maria/Marla, Jake/Jack, Elena/Helena). Avoid generic names that don't tell the reader anything.

### Dialogue (craft)

- [ ] **Subtext scan**: Pick 5 scenes at random. In each, find at least one line where the character means something different from what they say. If you can't find one, the dialogue may be too on-the-nose.
- [ ] **Monologue justification**: Every speech longer than 5 lines earns its length. Is the character saying something that couldn't be said shorter? Is the monologue the climax of a pressure that's been building?
- [ ] **First and last lines**: The first and last lines of dialogue in the script are disproportionately memorable. Are they worth remembering?

### Professionalism (presentation)

- [ ] **No typos in the first 5 pages**: Readers form impressions fast. A typo on page 1 colors everything that follows. Check the first 5 pages with extra care.
- [ ] **Consistent character name spelling**: Check that every character's name is spelled the same way throughout.
- [ ] **No orphaned CONT'D**: If a character's dialogue is split by action, the continuation is marked. If it's not split, there's no stray CONT'D.
- [ ] **Clean slug lines**: Scene headings don't have trailing spaces, inconsistent capitalization, or varying names for the same location.
- [ ] **Act breaks marked (TV only)**: If this is a TV pilot with act breaks, they're clearly marked (END OF ACT ONE, etc.).

## Process

1. Go through every item on the checklist. Check or flag each one.
2. Any flagged items get fixed before submission.
3. After fixes, re-check the flagged items.
4. Present the completed checklist to the writer for their review.
5. Only after the writer confirms: the draft is ready to go out.

## Rules

- **No skipping.** Every item is checked. "I'm sure it's fine" is not a check.
- **The writer makes the final call.** The checklist flags issues. The writer decides which matter enough to fix before submission. But they should see every flag.
- **This is not coverage.** Coverage is about story quality. This checklist is about professional presentation and basic story integrity. Coverage should have been done earlier.
- **Run this AFTER draft-locking.** The locked draft is what gets the checklist. If the checklist reveals issues that require changes, make the changes in a new revision, lock again, and re-run the checklist.
